## 🚀 Featured Project

### 🔹 DevSwipe — Developer Networking Platform

A full-stack application that enables developers to discover, connect and chat in real time.

**Key Highlights**
- Swipe-based discovery system
- JWT-based authentication
- Real-time one-to-one chat using WebSockets
- Persistent chat storage with MongoDB
- Optimized queries with indexing & pagination
- Deployed on AWS EC2 with Nginx & PM2

👉 Frontend Repository: https://github.com/bhvyx/devSwipe-web  
👉 Backend Repository: https://github.com/bhvyx/devSwipe
